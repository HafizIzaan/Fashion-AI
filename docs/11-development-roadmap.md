# Development Roadmap

Build incrementally. Before each phase, inspect the existing repository and preserve working functionality.

0. Requirements/repository inspection.
1. Foundation and UI shell.
2. Supabase database schema and RLS.
3. Google authentication and family roles.
4. Clothes Library and Storage.
5. AI provider settings and secure credentials.
6. Clothing scan and extraction.
7. Studio outfit builder and validation.
8. Outfit generation.
9. Credit engine and transaction ledger.
10. Generated Results: preview, download, save, share, delete.
11. Administration controls.
12. Responsive/mobile/accessibility refinement.
13. Testing, error states, security audit.
14. Vercel deployment and production verification.

Each phase should have clear acceptance criteria, tests, and a concise change report. Do not attempt the entire product in one uncontrolled implementation pass.
