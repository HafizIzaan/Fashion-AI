# UI Specification

## Visual direction
Premium editorial/minimalist monochrome fashion aesthetic. Use generous whitespace, strong typography, restrained controls, and large imagery. The interface should feel like a polished fashion workspace rather than a generic AI dashboard.

## Studio
- Left/sidebar navigation on desktop.
- Clear page title.
- Temporary base/model image upload.
- Outfit builder with visual slots for outerwear, top, bottoms/dress, shoes, accessories.
- Large outfit preview area.
- Generate action clearly shows credit cost.

## Clothes Library
- Filter by category.
- Add clothing action.
- Product-card grid using clean isolated garment images.
- Empty state explains how to add the first item.

## AI Extraction
- Show source outfit image.
- Scan action.
- Detected-item list with category, description, confidence, and selection state.
- Show total credit cost before generation.
- Generated item previews can be downloaded or saved.

## Settings
Use a simple settings navigation with Account, AI Providers, AI Models, Credits, Preferences, and admin-only Administration.

## Mobile
- Responsive layout.
- Compact/bottom navigation.
- Each outfit slot opens a library picker/drawer rather than relying on desktop drag/drop.
- Generate action remains easy to reach.
- Temporary model upload remains available.
